# Shahzad & Brothers Fertilizer - Premium Business Website

A modern, professional, and fully responsive website for **Shahzad & Brothers Fertilizer Okara**, a leading agricultural fertilizer supplier in Pakistan.

## 🌟 Project Overview

This is a complete HTML5, CSS3, and JavaScript-based website designed to showcase the company's products, services, and expertise in the agricultural sector. The site features a modern, premium design with smooth animations, interactive elements, and full mobile responsiveness.

## 🔧 Customization Guide

### Changing Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
  --primary-dark: #1a3a2a;
  --primary-green: #2d6a4f;
  --accent-gold: #d4af37;
  /* ... other colors ... */
}
```

### Adding Products
Edit the products grid in `products.html`:
```html
<div class="product-card">
  <div class="product-image"><i class="fas fa-icon"></i></div>
  <div class="product-content">
    <h4 class="product-name">Product Name</h4>
    <p class="product-desc">Description</p>
    <button class="btn btn-primary">View Details</button>
  </div>
</div>
```
